# Chaos Jungle 0.1.0a1

This is an alpha preview for early testers. This release brings the Python
package and both optional assistant skills together on one GitHub Release.
The Python package is not yet published to PyPI.

## Release files

| File | Purpose |
| --- | --- |
| `chaos_jungle-0.1.0a1-py3-none-any.whl` | Installable Python package |
| `chaos_jungle-0.1.0a1.tar.gz` | Python source distribution |
| `chaos-jungle-skills-v0.1.0a1.zip` | Skills for fault injection and resilience evaluation of agent-based and other software systems |

The skills ZIP contains the complete `chaos-jungle-injection/` and
`chaos-jungle-evaluation/` folders. They are instructions, not Python
dependencies or fault executables. No runtime fault mechanism changes are
claimed for this packaging release.

Codex and Claude Code can use the skills to plan experiments; the system under
test is not limited to a coding assistant and may be any supported agent or
application.

## Install the package

Download the wheel and install it in a Python 3.9+ virtual environment:

```sh
python -m pip install ./chaos_jungle-0.1.0a1-py3-none-any.whl
```

The wheel has no compiled Python extension, but infrastructure faults can
still require Linux tools, target privileges, and explicit preparation. See
the [installation guide](https://pegasus-isi.github.io/Chaos-jungle/guides/installation.html).

## Install the skills

For a user-level installation, download the skills ZIP and extract it into
the directory for your assistant:

```sh
# Codex
unzip chaos-jungle-skills-v0.1.0a1.zip -d ~/.agents/skills/

# Claude Code
unzip chaos-jungle-skills-v0.1.0a1.zip -d ~/.claude/skills/
```

Alternatively, from a project directory, the `skills` CLI can install both
skills from this tagged repository for both assistants:

```sh
npx skills add pegasus-isi/Chaos-jungle@v0.1.0a1 \
  --skill chaos-jungle-injection --skill chaos-jungle-evaluation \
  -a codex -a claude-code -y
```

The `npx` command reads the tagged repository's `skills/` directory; it does
not install the release ZIP or the Python package. The repository is currently
private, so repository access and configured Git authentication are required.
The current skills CLI requires Node.js 22.20 or newer.
Start a new assistant session after installation.
